# 📚 Bookfinder PWA

> A modern, responsive Progressive Web App (PWA) designed to seamlessly manage, search, and organize your personal library collection.

![GitHub Actions Deployment](https://github.com/jinsoojang-da/jinsoojang-da.github.io/workflows/Deploy%20Vite%20App%20to%20GitHub%20Pages/badge.svg)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

---

## ✨ Features

- **🔐 Secure Authentication**: Integrated with Firebase Auth to keep your reading data secure and personalized.
- **📱 Progressive Web App (PWA)**: Optimized for both mobile and desktop experiences with offline capabilities.
- **⚡ Lightning Fast**: Built with Vite and modern vanilla JavaScript for high performance and smooth interactions.
- **🎨 Custom UI**: Clean, intuitive interface featuring custom-styled components and responsive layouts.

---

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
- **Authentication & Database**: Firebase (Auth, Firestore)
- **Build Tool**: Vite
- **Deployment**: GitHub Actions & GitHub Pages
